# AI & Disinformation Analysis

## Overview
This project analyzes misinformation patterns, fact-check coverage, and automated fake news classification using Python, SQL, and machine learning.

A key aspect of this project is that two custom datasets were manually created from multiple credible news and fact-checking sources before conducting the analysis.

## Tools Used
- Python
- Pandas
- SQL
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Data Loading & Cleaning  
2. SQL Analysis  
3. EDA + Visualizations  
4. Cross-Dataset Analysis  
5. Machine Learning Model  
6. Key Findings Summary  
7. Final Conclusion  
8. Limitations  
9. Future Work

## Machine Learning
A baseline TF-IDF + Logistic Regression model was used to classify content into:
- TRUE
- FALSE
- MISLEADING

## Note
Custom datasets used in this project are not publicly included in this repository.
